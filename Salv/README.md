## A Oportunidade

### O Problema

O Brasil tem **70% da população adulta endividada** (Serasa, 2025). A raiz não é falta de renda — é falta de **consciência financeira e ferramentas acessíveis**.

| Dor do Mercado | Impacto |
|----------------|---------|
| Apps financeiros são caros (R$15–40/mês) | Exclui justamente quem mais precisa |
| Interfaces complexas e burocráticas | Usuário abandona em dias |
| Foco em planilha, não em comportamento | Não gera mudança real de hábito |
| Sem educação financeira integrada | Ferramenta sem contexto não transforma |
| Dados bancários manuais | Fricção alta = desistência |

### O Mercado

| Indicador | Valor |
|-----------|-------|
| Smartphones ativos no Brasil | 260M+ |
| Adultos sem controle financeiro | ~110M |
| Mercado de personal finance apps (LATAM) | US$ 2.4B (2026 est.) |
| Penetração Open Finance (BR) | 27M de consentimentos ativos |
| TAM estimado (Brasil, classe C/D/E) | 80M+ de potenciais usuários |

> A janela é agora: Open Finance maduro, BaaS acessível, e uma geração inteira que vive no celular mas não sabe para onde vai o salário.

## O que é o Salv

**Salv** é um aplicativo mobile de **educação e gestão financeira pessoal** projetado para ser o primeiro contato saudável que milhões de brasileiros terão com o controle do próprio dinheiro.

Não é um banco. Não é uma planilha glorificada. É um **coach financeiro de bolso** — gamificado, gratuito e que evolui junto com o usuário.

---

## Por que "Salv"

O nome **Salv** carrega em quatro letras a essência do produto:

> **Salvar. Resgatar. Proteger.** A ação mais fundamental que alguém pode fazer pelo próprio futuro financeiro.

A escolha foi intencional em cada dimensão:

| Dimensão | Intenção |
|----------|----------|
| **Significado** | Deriva de "salvar" — o ato de resgatar o controle financeiro da própria vida. Não é sobre acumular riqueza; é sobre se proteger do caos. |
| **Estética** | Minimalista, moderno, com DNA de fintech global. Quatro letras. Sem adorno. Direto ao ponto. |
| **Sonoridade** | Curto, fluido e altamente memorável para o público brasileiro. Fácil de falar, fácil de buscar, impossível de esquecer. |
| **Posicionamento** | Não soa como banco tradicional. Não soa como planilha. Soa como algo novo — porque é. |

O Salv não pede que o usuário seja disciplinado. Ele torna o controle financeiro tão natural quanto abrir o Instagram. O nome reflete isso: leve, acessível, sem peso.

## Roadmap Estratégico

### A Estratégia "Cavalo de Troia"

O Salv não nasce como fintech. Nasce como **app de hábito** — rápido, divertido, viciante. A monetização pesada e a infraestrutura bancária vêm depois, quando a base já está consolidada e engajada.

```
FASE 1                    FASE 2                     FASE 3
Tração & Hábito           Monetização Premium        Conta Digital
─────────────────────────────────────────────────────────────────
[App gratuito]     →      [Open Finance]      →     [BaaS Nativo]
[Gamificação]      →      [Sync automático]   →     [Conta + Cartão]
[Viralidade]       →      [Dados proprietários]→    [Crédito + Seguros]
[Ads como receita] →      [Premium com valor] →     [Interchange + Float]

Foco: USUÁRIOS            Foco: RECEITA              Foco: PLATAFORMA
Meta: 1M MAU              Meta: R$5M ARR             Meta: Banco digital
```

---

### Fase 1 — Tração & Criação de Hábito

**Objetivo:** Adquirir massa crítica com um app leve, rápido e viciante.

**Timeline estimado:** 6–9 meses (MVP → escala inicial)

| Funcionalidade | Propósito Estratégico |
|----------------|----------------------|
| Onboarding em 30 segundos | Eliminar fricção; ativar imediatamente |
| Registro manual de gastos (simplificado) | Criar o hábito de olhar para o dinheiro |
| Categorização inteligente (com sugestões) | Reduzir esforço cognitivo |
| Metas financeiras visuais | Dar propósito ao controle |
| Micro-aulas de educação financeira | Ensinar enquanto o usuário usa |
| Sistema de XP, streaks e conquistas | Retenção via dopamina e progresso |
| Rankings entre amigos | Viralidade orgânica (convites) |
| Alertas de gastos e lembretes | Push engagement diário |
| Dashboard mensal com insights | Valor percebido imediato |
| Anúncios contextuais (ads financeiros) | Receita desde o dia 1 |

**KPIs da Fase 1:**

| Métrica | Meta |
|---------|------|
| Downloads (6 meses) | 500K+ |
| MAU | 200K+ |
| Retenção D7 | > 50% |
| Retenção D30 | > 35% |
| NPS | > 50 |
| Sessões/dia por usuário | 1.5+ |

### Fase 3 — Conta Digital Nativa (BaaS)

## Arquitetura de Produto

### Experiência do Usuário (Jornada)

```
DOWNLOAD → ONBOARDING (30s) → PRIMEIRO GASTO REGISTRADO (< 2min)
    ↓
STREAK ATIVADO → MICRO-AULA DESBLOQUEADA → BADGE CONQUISTADO
    ↓
CONVIDA AMIGO → RANKING ATIVO → HÁBITO FORMADO (7 dias)
    ↓
META FINANCEIRA → PROGRESSO VISÍVEL → RETENÇÃO CONSOLIDADA
    ↓
[FASE 2] SYNC BANCÁRIO → INSIGHTS AUTOMÁTICOS → PREMIUM
    ↓
[FASE 3] CONTA DIGITAL → PLATAFORMA FINANCEIRA COMPLETA
```

### Princípios de Design

| Princípio | Aplicação |
|-----------|-----------|
| **Speed over features** | App abre em < 1s; registro de gasto em 2 toques |
| **Dopamina controlada** | Cada ação gera feedback visual + XP |
| **Zero jargão financeiro** | Linguagem simples, tom amigável |
| **Mobile-first (e only na Fase 1)** | Foco total na experiência mobile |
| **Dark patterns = proibido** | Confiança é o ativo principal |
| **Acessibilidade radical** | Funciona em celulares entry-level, conexão 3G |

### Gamificação — Sistema de Progressão

```
┌─────────────────────────────────────────────────────────────┐
│                  SISTEMA DE PROGRESSÃO                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  XP (Experience Points)                                     │
│  ├── Registrar gasto: +10 XP                                │
│  ├── Completar micro-aula: +25 XP                           │

│  └── Convidar amigo ativo: +150 XP                          │
│                                                             │
│  STREAKS                                                    │

│  ├── Multiplicador de XP a cada 7 dias                      │
│  └── Streak freeze (1 por semana para Salv+)                │
│                                                             │
│  NÍVEIS                                                     │
│  ├── Iniciante → Consciente → Organizado →                  │
│  │   Estrategista → Mestre Financeiro                       │
│  └── Cada nível desbloqueia conteúdo e features visuais     │
│                                                             │

> O Salv começa como um app de hábito financeiro. Termina como a **conta digital de dezenas de milhões de brasileiros** que aprenderam a cuidar do dinheiro dentro dele.

```
APP DE HÁBITO → GESTOR FINANCEIRO → PLATAFORMA FINANCEIRA → BANCO DIGITAL

**O ativo mais valioso não é a tecnologia — é a base de usuários engajados e os dados de comportamento financeiro que só o Salv terá.**
